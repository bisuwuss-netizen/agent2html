# 颜色配置系统优化记录

## 📅 修改时间
2026-01-07

## 🎯 优化目标
移除LLM生成颜色配置,完全使用系统预设的专业配色方案,确保视觉一致性和可读性。

---

## ❌ 修改前的问题

### 1. LLM生成颜色不可靠
```json
// LLM可能生成的颜色(错误示例)
"style_config": {
  "color": {
    "primary": "#1E293B",      // 深色
    "text": "#2C3E50",         // 深色文字
    "background": "#1a252f"    // 深色背景
  }
}
// 结果: 深色背景 + 深色文字 = 看不见内容!
```

### 2. 系统提示词要求LLM生成颜色
- `src/agents/planner.py:212-226` 要求LLM生成 `color` 字段
- LLM每次生成的颜色不一致
- 可能不符合WCAG无障碍标准
- 覆盖了精心设计的专业配色

### 3. 需要手动修复
```python
# 被迫在多个地方强制覆盖LLM生成的颜色
if 'style_config' in planning:
    planning['style_config']['color'] = style_config['color']
```

---

## ✅ 修改后的方案

### 1. 移除颜色生成要求

**修改文件**: `src/agents/planner.py`

**系统提示词 (第218-227行)**:
```json
"style_config": {
  "style_name": "theory_clean|practice_industrial|safety_warning",
  "font": {
    "title_family": "Microsoft YaHei",
    "body_family": "Microsoft YaHei"
  },
  "layout": {
    "notes_area": true
  }
}
// 不再要求LLM生成 "color" 字段
```

**添加明确说明 (第285-291行)**:
```
【style_config 说明】
只需要选择 style_name，不要生成 color 字段！
- theory_clean: 专业理论课(系统将根据专业自动匹配配色)
- practice_industrial: 实训操作课(强调操作和安全)
- safety_warning: 安全规范课(使用警示配色)

注意: 配色(color)由系统根据用户的"专业"字段自动匹配，不需要在 JSON 中生成！
```

### 2. 统一颜色清理逻辑

**修改文件**: `src/agents/planner.py`

**在 `_validate_and_enhance()` 函数中统一处理 (第386-389行)**:
```python
# 强制移除 style_config 中的 color 字段(如果存在)
# 颜色由系统根据专业自动匹配,不应该由LLM生成
if 'style_config' in planning and isinstance(planning['style_config'], dict):
    planning['style_config'].pop('color', None)
```

### 3. 简化调用代码

移除了之前在多处添加的临时修复代码:
- JSON直接输入模式 (第120-127行) - 已简化
- LLM生成模式 (第153-160行) - 已简化

现在统一在 `_validate_and_enhance()` 中处理,代码更清晰。

## 🎨 配色系统架构

### 职责划分

| 组件 | 职责 | 示例 |
|-----|------|------|
| **LLM (planner.py)** | 内容规划、结构设计 | "这是实训课,需要steps布局,选择practice_industrial风格" |
| **Config (config.py)** | 专业配色、视觉规范 | "护理学用粉红色 #e91e63,机械用蓝灰色 #2c3e50" |

## 💡 最佳实践

### LLM应该负责
- ✅ 内容规划(主题、知识点、教学目标)
- ✅ 结构设计(页数、页面类型、布局选择)
- ✅ 教学场景识别(theory/practice/safety)

### LLM不应该负责
- ❌ 颜色配置(由config根据专业匹配)
- ❌ 字体设置(由config统一管理)
- ❌ 尺寸规格(由config统一管理)

### 配色管理原则
1. **集中管理**: 所有配色在 `src/config.py` 统一定义
2. **专业映射**: 根据专业名称自动匹配配色
3. **场景微调**: teaching_scene 只影响 accent 色(如实训用绿色,安全用红色)
4. **LLM隔离**: LLM完全不接触颜色生成,只选择 style_name

**注意**:
- 保证 `text` 和 `background` 有足够对比度 (建议 > 7:1)
- 使用在线工具验证: https://webaim.org/resources/contrastchecker/

### 调整教学场景配色
**修改文件**: `src/agents/generator.py:96-104`

```python
def _get_colors(self, user_input: Dict, teaching_scene: str = 'theory') -> Dict:
    colors = config.get_colors_for_major(major)
    if teaching_scene == 'practice':
        colors = {**colors, 'accent': '#27ae60'}  # 绿色
    elif teaching_scene == 'safety':
        colors = {**colors, 'accent': '#e74c3c'}  # 红色
    return colors
```
